# DP Agencia Deportiva — Studio-DP

CMS de DP Agencia Deportiva. Estudio de contenido basado en [Sanity Studio](https://www.sanity.io/).

- **Proyecto Sanity:** DP Agencia Deportiva
- **Project ID:** `ugd8kors`
- **Dataset:** `production`

## Requisitos

- Node.js 20+

## Empezar

```bash
npm install
npm run dev
```

Abre [http://localhost:3333](http://localhost:3333).

## Scripts

| Script                   | Qué hace                           |
| ------------------------ | ----------------------------------- |
| `npm run dev`             | Servidor de desarrollo del Studio  |
| `npm run build`           | Build de producción del Studio     |
| `npm run start`           | Sirve el build de producción       |
| `npm run deploy`          | Despliega el Studio en Sanity      |
| `npm run deploy-graphql`  | Despliega el API GraphQL en Sanity |
